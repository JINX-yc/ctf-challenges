# CTF Challenges

A collection of CTF challenges I designed and built, spanning OSINT, Cryptography, and Misc.

| Challenge | Category | Points
|---|---|---|
| [The Zodiac Archive](osint/zodiac-archive/) | OSINT | 150 
| [Blue Anchor Imports](osint/blue-anchor-imports/) | OSINT | 300 
| [Signal Loss](cryptography/signal-loss/) | Cryptography | 150 
| [Time Machine](misc/time-machine/) | Misc | 150

Each challenge folder contains a player-facing `README.md` (description, flag format, and any setup instructions), a `files/` folder with the artifacts given to players, and a `solution/writeup.md` with the full solve path (secrets redacted — see note below).

> **Note:** Solution writeups intentionally redact passwords, decoded strings, and final flags with `[REDACTED]`. The full methodology and reasoning is documented and only the exact answers are withheld, so the writeups can't be used to skip solving.
